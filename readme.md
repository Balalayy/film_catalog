# Каталог фильмов 

Приложение для ведения каталога фильмов, разработанное на Python с использованием библиотеки PyQt6. 

## ТЗ
Программа позволяет вести базу данных фильмов, разделенных по жанрам. 
Основные возможности:
- Просмотр списка фильмов в виде таблицы.
- Добавление, редактирование и удаление фильмов.
- Поиск по названию и фильтрация по жанру.
- Загрузка и отображение постеров (картинок) для фильмов.
- Использование горячих клавиш (Ctrl+N, Delete, Esc и др.) и контекстного меню мыши.
